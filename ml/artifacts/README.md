# Model Artifacts

This directory stores generated model artifacts. Most files are gitignored.

## Expected files (generated — not committed)

| File | Generated by | Description |
|---|---|---|
| `features/features.npy` | `extract_features.py` | Log-Mel feature matrix |
| `features/labels.npy` | `extract_features.py` | Class labels |
| `features/metadata.pkl` | `extract_features.py` | Feature extraction parameters |
| `norm_stats.npz` | `train.py` | Feature normalization mean/std |
| `model.pth` | `train.py` | PyTorch checkpoint (best val accuracy) |
| `model.onnx` | `export.py` | ONNX intermediate |
| `model.tflite` | `export.py` | TFLite model for ESP32-S3 |

## Model not yet trained

No recordings have been collected. The pipeline is ready to accept data.

See [`docs/dataset.md`](../../docs/dataset.md) for collection instructions.

## Note on committing artifacts

- `model.pth` — commit only if small and appropriate for public release
- `model.tflite` — commit for embedded deployment convenience
- `features/*.npy` — do **not** commit (large, reproducible from data)
- `norm_stats.npz` — commit alongside the model checkpoint

Adjust `.gitignore` when artifacts are ready.
